# September 8: Started designing ESP32 PCB
I started working on my custom ESP32 PCB project in EasyEda. I worked on the initial board layout and started placing the components required for board layout and started placing the components required for the ESP32 development board. I focused on arranging the main components and making the board layout clean and organized.
